# Calendrier Grist V4 — Services depuis le référentiel

Cette version charge la liste complète des services depuis `REF_service_utilisateur`.

- Nouvelle action : tous les services du référentiel sont sélectionnables.
- Cela fonctionne aussi pour créer la toute première action d’un service.
- Modification d’un événement : même liste complète.
- Filtre Service : liste complète du référentiel.
- La valeur écrite dans `Toutes les actions BMEO.Service` est l’ID de référence Grist, pas un simple texte.

Remplace uniquement le `index.html` à la racine de GitHub.
